Uso quotidiano

La barra "aggiungi contenuto" si estende da sola

Il manifest di un plugin dichiara i pulsanti e i pannelli che contribuisce. La shell li monta a runtime: nessuna ricompilazione, nessun riavvio.

"+ Versetto" non apre un piccolo popup: apre il pannello dedicato qui sotto — a schermo pieno, perché cercare un passo biblico è un lavoro a sé, non una casella in più nella barra.

// quello che il plugin "Bibbia" dichiara nel suo manifest.json { "id": "it.lzrhive.cuelith.plugin.bible", "category": ["religioso"], "composer_button": { "label": "Versetto", "opens": "ui.entry" }, "ui": { "entry": "index.html" } }

L'interfaccia studiata per questo plugin

Il pannello di Bibbia, a schermo intero

Non un popup con tre caselle: uno spazio pensato per come si cerca davvero un passo — sfogliando un capitolo intero, cercando una frase, o confrontando due traduzioni — con tutto quello che scegli via via raccolto in basso prima di mandarlo in scaletta.

Plugin "Bibbia" — cerca e aggiungi

Click per un versetto, Shift+click per selezionare tutto l'intervallo fino all'ultimo cliccato.

Shift+click funziona anche qui, sui risultati della ricerca.

Gestione

Plugin installati

Si disattivano senza disinstallarli (utile per uno show specifico), o si rimuovono del tutto — la barra "aggiungi contenuto" torna com'era.
