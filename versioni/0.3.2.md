Disinstallare un plugin che sta girando ora funziona sempre, e installare un plugin da file o da cartella mostra che il lavoro è in corso.

## Novità

- **Disinstallare un plugin in funzione**: prima su Windows poteva comparire «Errore interno del motore» e il plugin restava nell'elenco a metà. Ora Cuelith ferma il plugin, aspetta che si chiuda e poi toglie i file. Se qualche file resta occupato, viene tolto al prossimo avvio.
- **Si vede che sta lavorando**: installando da file o da cartella, e disinstallando, compare «Installazione in corso…» (o «Disinstallazione in corso…») con un indicatore, e i pulsanti restano bloccati finché non finisce.

## Da sapere

- Lingue italiano **0.2.4** e inglese **0.1.4** incluse nell'installatore.
- I plugin già installati e i tuoi file non cambiano.

Uninstalling a plugin that is running now always works, and installing a plugin from a file or a folder shows that work is in progress.

## What is new

- **Uninstalling a running plugin**: on Windows it could previously show "Internal engine error" and leave the plugin half-removed in the list. Cuelith now stops the plugin, waits for it to close, then removes the files. If a file stays busy, it is removed at the next start.
- **You can see it working**: installing from a file or folder, and uninstalling, now shows "Installing…" (or "Uninstalling…") with an indicator, and the buttons stay disabled until it finishes.

## Good to know

- Italian **0.2.4** and English **0.1.4** languages are included in the installer.
- Plugins you already installed and your files do not change.
