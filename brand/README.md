# Marchio di Cuelith

File originali del logo, forniti dal fondatore. Non modificarli: ogni uso nell'app parte da qui.

| File               | Cosa                                                                                              | Dove si usa                                                                           |
| ------------------ | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `cuelith-icon.png` | Icona originale, 1024×1024, con trasparenza                                                       | Icona della finestra (`apps/desktop/build/icon.png`) e, in futuro, degli installatori |
| `cuelith-icon.svg` | La stessa icona in vettoriale, ricostruita misurando i pixel dell'originale e confrontata a vista | Icona della pagina (`apps/client/public/brand/`)                                      |
| `cuelith-logo.png` | Logo con scritta, 2400×779, sul nero della postazione (`#0B0C0E`)                                 | Barra in alto e schermata di avvio (`apps/client/public/brand/`)                      |

Colori: ciano `#37D1BF` (= `--cl-cue`), scritta chiara `#ECEAE4` (= `--cl-fg`), fondo `#0B0C0E` (= `--cl-bg`).

La scritta non è ricostruita in vettoriale: il carattere del logo non coincide con quello dell'interfaccia, e un'approssimazione altererebbe il marchio. Se esiste l'originale vettoriale (SVG/AI/PDF), va aggiunto qui e sostituisce i PNG.
